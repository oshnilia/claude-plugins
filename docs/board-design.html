Доска сессии — что показывать и как

Макет на реальных данных этой сессии. Каждый вид отвечает на один вопрос того, кто следит за работой Claude. Жёлтые метки — из каких элементов мода собран блок (Svg рисуется картинкой и перерисовывается раз за ход, остальное — родные элементы).

1. Сверху — то, что требует тебяВопросы к тебе, ошибки, блокеры. Если ничего — блока нет.
2. Прогресс, а не список узловЦель → шаги: что готово, что сейчас, что дальше. Дерево узлов само по себе ничего не говорит.
3. «Почему» — цепочкойВопрос → что пробовали (✗ / ✓) → решение. Доказательства — по клику.
4. Одно главное действие на блокPrimary-кнопка одна. Остальное — secondary или plain-ссылки «подробнее».
5. Без внутренних idD1, C1 — для Claude. Человек видит метки «решение», «правило», «тупик».

Полоса над промптом

Видна всегда. Одна строка: главное + что ждёт тебя.

◆Маркетплейс и legible готовы. Доска: дизайн видов.нужен ты · 2доскаText + Button plain
Как это собирается из элементов мода. Вкладки — Button plain hotkey. Главное действие блока — Button variant="primary", одно на блок. Вторичные — Button по умолчанию; «подробнее ▸», «проще», «схемой» — Button plain. Ответ на вопрос — Input с submitLabel, открывается по кнопке. Фильтр по цели — Select. Метки «решение», «тупик» — Text backgroundColor. Полосы прогресса, цепочка «почему», столбики усилий и клетки файлов — Svg-картинки, перерисовываются только когда меняется журнал. Ответы в «Спросить» — Markdown.
