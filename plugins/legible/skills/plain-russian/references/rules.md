# Упрощённый технический русский: правила и примеры

Источники идей: ASD-STE100 (структурные правила), информационный стиль (М. Ильяхов, Л. Сарычева, «Пиши, сокращай»),
Нора Галь, «Слово живое и мёртвое» (канцелярит). Формулировки — наши.

Обозначения: **[S]** — проверяет скрипт `ru_score.py`, **[R]** — проверьте при чтении.

## 1. Слова
- Простые слова с одним значением. [R]
- Один термин — одно значение; не меняйте синонимы ради разнообразия. [R]
- Глагол вместо отглагольного существительного. [S — цепочки]
  - было: «Осуществляется проверка корректности заполнения полей.»
  - стало: «Скрипт проверяет, что поля заполнены верно.»
- Без канцелярита. [S — список]
  - «является» → «это» или глагол; «данный» → «этот»; «в рамках» → «в», «во время»; «в целях» → «чтобы»;
    «посредством» → «через», «с помощью»; «на сегодняшний день» → «сейчас»; «в случае если» → «если».
- Без пустых слов: «в принципе», «на самом деле», «достаточно», «определённый», «различные». [S на 100]

## 2. Глаголы
- Действительный залог. [S]
  - было: «Ошибка была найдена в модуле оплаты.»
  - стало: «Тест нашёл ошибку в модуле оплаты.»
- Без возвратного пассива «производится, осуществляется, выполняется». [S]
- В инструкциях — повелительное наклонение на «вы»: «откройте», «запустите». [S — распознаёт инструкцию]
- Без безличных «необходимо», «следует», «требуется»: дайте команду или назовите исполнителя. [S на 100]

## 3. Предложения
- Описание — до 25 слов, инструкция — до 20. [S]
- Одно действие на предложение. [S]
  - было: «Откройте файл и удалите старую строку.»
  - стало: «Откройте файл. Удалите старую строку.»
- Условие перед командой. [S]
  - было: «Перезапустите сервер, если порт занят.»
  - стало: «Если порт занят, перезапустите сервер.»
- Без причастных оборотов: «который …» или отдельное предложение. [S — эвристика]
- Без деепричастных оборотов в инструкциях. [S]
- Без «;». [S]

## 4. Абзацы и порядок
- Сначала вывод, потом детали (пирамида Минто, BLUF). [R]
- Абзац — одна тема, не больше 6 предложений. [S]
- Перечисление из 3+ элементов — вертикальным списком. [R]

## Что значит «80%»
plain-ru-80 = все правила [S] уровня 80 + правила [R]. Оценка — доля предложений без замечаний.
Текст проходит plain-ru-80 при оценке 0.8 и выше.
