# Упрощённый технический русский (plain-ru)

Стиль вдохновлён ASD-STE100 и информационным стилем. Стандарт ASD-STE100 есть только для английского;
это наш собственный набор правил. Не называйте текст «соответствующим ASD-STE100».

## Уровни

| Уровень | Для чего | Что добавляется |
|---|---|---|
| plain-ru-50 | чат, лёгкая правка | короткие предложения, без «;», без пассива |
| **plain-ru-80** (по умолчанию) | ответы, доки, сводки, доска сессии | + правила ниже |
| plain-ru-100 | инструкции, тексты для агентов | + без пустых слов и безличных «необходимо/следует» |

## Правила plain-ru-80

1. Сначала ответ, потом причины.
2. Инструкция — не длиннее 20 слов. Описание — не длиннее 25 слов.
3. Одно действие на предложение. Повелительное наклонение: «Откройте файл».
4. Условие перед командой: «Если тест упал, прочитайте лог».
5. Действительный залог: назовите, кто делает. «Скрипт изменил конфиг», а не «конфиг был изменён».
6. Глагол вместо отглагольного существительного: «проверить», а не «осуществить проверку».
7. Без цепочек «-ние/-ция»: «проверка соответствия требованиям» → «проверить, что … выполняет требования».
8. Без канцелярита: «является», «данный», «в рамках», «в целях», «посредством», «осуществлять».
9. Без причастных и деепричастных оборотов в инструкциях: «Открыв файл, нажмите…» → два шага.
10. Без «;». Один абзац — одна тема, не больше 6 предложений.
11. Один термин — одно значение во всём тексте. Английские термины и код оставляйте как есть.

Не превращайте текст в инструкцию по ремонту самолёта. Сохраняйте смысл и честную неуверенность («вероятно»).

## Измерить и исправить

```bash
python3 "${CLAUDE_SKILL_DIR}/scripts/ru_score.py" --level 80 draft.md
```

`-` читает stdin, `--json` — машинный вывод. Скрипт проверяет только структуру, смысл слов перечитайте сами.
Если пользователь просил уровень, закончите строкой: `plain-ru-80: 90%`.

Полные правила с примерами «было → стало»: [references/rules.md](references/rules.md).
